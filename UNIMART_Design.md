# UNIMART DESIGN.md

## Product Summary

UNIMART is a university-exclusive marketplace where verified students can safely buy and sell items inside their campus ecosystem.

The design must communicate:

- trust
- verification
- safety
- academic credibility
- smooth usability
- premium product quality

---

## Design Direction

Use the following blend:

- **80% Soft Bento SaaS**
- **15% Academic Elite**
- **5% Liquid Glass**

This should feel like a premium student marketplace, not a generic e-commerce site.

### Core visual principles

- full-width layouts
- spacious composition
- clear hierarchy
- soft shadows
- rounded containers
- subtle glass where useful
- product-first browsing

---

## Brand Reference

Use the uploaded UNIMART logo as the brand anchor.

Interpret the logo as:

- indigo / violet primary identity
- navy / slate support tones
- academic confidence
- modern marketplace energy

The logo should influence:

- navigation treatment
- buttons
- badges
- active states
- section highlights

---

## Color System

### Backgrounds
- Base background: `#F8F9FF`
- Surface: `#FFFFFF`
- Soft surface: `#F4F6FB`
- Card surface: `#FFFFFF`
- Glass surface: `rgba(255, 255, 255, 0.72)`

### Brand
- Primary: `#4F46E5`
- Primary hover: `#4338CA`
- Secondary: `#0F172A`
- Accent blue: `#6366F1`

### Text
- Primary text: `#0B1C30`
- Secondary text: `#566074`
- Muted text: `#7C8598`

### Borders / Dividers
- Border light: `#E2E8F0`
- Border softer: `#EEF2F7`

### Status
- Success: `#10B981`
- Warning: `#F59E0B`
- Error: `#EF4444`

Use color sparingly and keep the overall feel calm.

---

## Typography

### Primary font
- **Inter**

### Optional headline accent
- **Space Grotesk** or **Plus Jakarta Sans** for hero headings only, if it improves hierarchy without harming consistency

### Typographic hierarchy
- Hero display: large, bold, confident
- Section headings: clear, concise, premium
- Body text: comfortable line-height and strong readability
- Labels and badges: compact and refined

Typography should feel modern, smooth, and high-trust.

---

## Layout System

### Grid
- Desktop: 12-column layout
- Tablet: 8-column layout
- Mobile: 4-column layout

### Spacing
- 8px base grid
- Generous section spacing
- Large vertical breathing room
- Balanced card padding

### Page width
- Max content width around `1280px` to `1440px`

---

## Navigation

Create a floating top navigation bar.

Include:

- UNIMART logo
- search bar
- Browse
- Sell
- Orders
- notifications
- profile/avatar menu

Navigation style:

- softly elevated
- lightly translucent
- rounded pill or rounded rectangle
- premium but functional

---

## Hero Section

The hero should be full-width and visually dominant.

### Requirements
- large headline
- short supporting text
- primary CTA
- secondary CTA
- large product collage or marketplace illustration
- premium background treatment
- strong trust cue

### Hero copy
Suggested headline:

**Buy & Sell with Campus Students**

Suggested subtext:

Verified students. Secure transactions. Trusted university marketplace.

### Hero visual
Use a polished product collage or campus-inspired composition with:
- laptop
- phone
- backpack
- textbooks
- subtle academic environment cues

Do not keep the content compressed to the left side. The composition must feel wide, balanced, and premium.

---

## Trust Section

Add a dedicated trust section titled:

**Why Students Trust UNIMART**

Include these points:

- Verified Students
- Secure Transactions
- Campus-only Marketplace
- OTP Handover System

Present them as premium bento cards or trust chips.

---

## Product Discovery

### Category chips
Use pill-shaped category filters with:
- Textbooks
- Electronics
- Notes & Study Material
- Lab Equipment
- Furniture
- Clothing
- Bicycles
- Sports

### Product cards
Product cards must have:
- larger image emphasis
- verified seller badge
- favorite/save action
- clean title hierarchy
- location or campus metadata
- subtle hover lift
- rounded corners around 24px or more

Make cards feel polished and smooth, not cramped.

---

## Listing Section

The listings area should feel airy and structured.

Include:
- filter button
- sort dropdown
- empty state or product grid
- clear spacing between cards

If no products are present, the empty state should look refined and intentional.

---

## Dashboard / Bento Area

Use a bento-style structure for:
- metrics
- student stats
- orders
- activity
- quick actions

This area should feel modular, clean, and premium.

---

## Footer

Create a minimalist footer with:
- brand summary
- categories
- quick links
- stay updated form
- soft icon row

Footer style should be simple, elegant, and aligned with the overall academic brand.

---

## Motion

Use only subtle, premium motion.

Allowed:
- hover lift
- soft scaling
- fade transitions
- gentle entrance motion
- smooth button feedback

Avoid:
- flashy movement
- exaggerated bounce
- heavy parallax
- over-animated backgrounds

Motion should feel smooth and trustworthy.

---

## Liquid Glass Usage

Use liquid glass only where it improves the interface:

- navbar
- search bar
- dropdowns
- modal surfaces
- selected chips
- small highlight cards

Do not overuse blur or glass effects.

Glass should be a refinement, not the main theme.

---

## Accessibility

Requirements:
- strong contrast
- readable text sizes
- clear focus states
- keyboard support
- mobile-friendly interactions

---

## Scope Rules

Do not modify:
- backend logic
- authentication flows
- APIs
- database schema
- admin module UI
- admin routes
- routing architecture unless absolutely necessary for rendering

The redesign is for the student-facing experience only.

---

## Final Goal

Create a smooth, premium, high-trust university marketplace that feels like a real product company’s work.

The final result should look closest to:
- a modern SaaS product
- a clean campus marketplace
- a polished startup interface

Prioritize:
1. usability
2. trust
3. smoothness
4. visual clarity
5. premium polish
